# Assets

This folder is reserved for visual documentation assets used in the repository.

Recommended contents:

- UI screenshots for the local demo
- architecture images exported for presentations
- short GIF captures for portfolio walkthroughs

Suggested naming:

- `ui-home.png`
- `ui-sql-example.png`
- `ui-rag-example.png`
- `architecture-overview.png`

Guideline:

- do not place confidential data here
- use only local demo data shown by the project
- keep images lightweight and recruiter-friendly
